# Abrir el diagrama en draw.io (diagrams.net)

1. Descarga `Apellido_Nombre_DER_Lab3.drawio`.
2. Abre https://app.diagrams.net/.
3. Selecciona **Archivo → Abrir desde → Dispositivo** (o arrastra el archivo al lienzo).
4. Elige el archivo `.drawio`. Todas las tablas, textos y relaciones son elementos editables.
5. Para exportarlo, usa **Archivo → Exportar como → PNG / PDF / SVG**.

El diagrama se generó a partir de las tablas y claves foráneas de `sql/Apellido_Nombre_Aduana_Lab3.sql`. Incluye 16 tablas y una relación por cada FK, incluidas las dos referencias de país en declaraciones, el origen/destino de los movimientos y la relación recursiva del supervisor.
